# Hearthline brand kit
Concept: an H whose lower counter is a hearth arch, with a single ember inside.
Palette: Forest #1F3D36 · Ivory #F7F1E5 · Terracotta #C4552D (on dark: #E38A5F) · Mono #1A1A1A / #FFFFFF
Type: tracked serif capitals (wordmark is outlined paths, no font needed). Site headings use Georgia.
Files: svg/ (vector, use first) · png/ (transparent; horizontal 2400/600px, mark 1024/256px, icon 512/192/32/16px)
Use `horizontal` on light backgrounds, `-reversed` on dark or forest, `-mono-*` for single-colour print/stamps.
Clear space: at least the height of the ember circle on every side. Minimum width: horizontal 120px, mark 16px.
Do not recolour the ember, stretch, or add effects.
